# AgentGate interface

The new approval PWA inherits the existing extension's dark navy surfaces, mint primary actions, subdued blue text and familiar sans-serif typography. It is an operational interface used briefly on a phone. The primary content is the task, its scope, its expiry and the exact next action; no decorative hero or metrics dashboard.

Use a single-column approval inbox on mobile. A selected request expands inline into a readable permission receipt. Automatic mode presents one session-purpose approval. Optional communication and payment checkboxes start off; the payment checkbox reveals a total USD session limit. Explicit confirmation modes expose the exact target and staged values before an action-approval button. Desktop pairing and browser-view review use the same typography, form controls, focus states and palette. A task's lifecycle is a short textual sequence. Empty, offline, expired, revoked, loading and completed states carry specific next steps.

Semantic colors: mint for approval and connected state, amber for pending approval, red for denial and revocation. Keep private previews separate from published views with explicit button labels and local-only copy. Use authored SVG icons and the system sans font for this operational surface. Motion only highlights a changed approval stage and honors reduced motion.

Checkout approval shows the prepared order, merchant and exact USD total, followed by only missing fields. Use **Approve and place order** for the final action. Keep entered values in phone memory until submission or expiry; encrypt them to the task browser. The assistant waits while AgentGate fills and submits the existing cart.
