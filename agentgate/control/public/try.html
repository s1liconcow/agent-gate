Try a scoped browser task with approval on your phone. This trial has its own phone and browser connection.

You need desktop Chrome 138+ and an approval phone. Use Claude for the easiest trial; ChatGPT write actions need an eligible workspace.

1. Pair your approval phone

Open your private invitation link to show the phone setup QR.

Open on this phone

Scan with Android Chrome, then tap Pair this phone. Keep that phone browser open for approvals. This invitation registers one phone; share it only with your tester.

2. Connect desktop Chrome

Download the extension and unzip it. Open chrome://extensions, enable Developer mode, choose Load unpacked and select the unzipped folder.

Click the AgentGate toolbar icon → Connect browser → Pair with phone. Scan this second QR in the same phone browser and approve Browser connection. Then choose Allow approved tasks on websites and Enable automatic tasks once. Choose Chrome on-device AI, or save a remote provider and API key with remote-sharing consent. Chrome may download its local model; remote inference needs no download. Close setup when ready.

3. Add your assistant

In Claude, use Customize → Connectors → Add custom connector. Enter the endpoint, choose Sign in now and Register automatically for the OAuth client. Keep the sign-in window open and approve the assistant connection on your phone. Enable the connector in your conversation.

ChatGPT setup and availability

On ChatGPT web, enable Settings → Apps → Advanced settings → Developer mode, then create an OAuth MCP app with the endpoint above. Approve the connection on your phone and select the app in a conversation. Full browser actions currently require Business, Enterprise or Edu workspace permissions. Pro supports custom read/fetch connections only. ChatGPT agent mode does not use custom apps.

If Chrome’s local model is unavailable

Choose a remote inference provider in extension setup, save your API key, test with synthetic data and enable automatic tasks. Each phone approval names the remote provider and explains candidate sharing. For manual review instead, Ask the assistant to start a session with manual disclosure. In the extension, use Capture selected text & controls, select only To, Subject, Message and Send demo email, review their labels and the text, check consent, then publish. Existing input values are excluded. Only mark a field Stage in session if typing does not commit a change; these demo fields are safe to stage.

Other synthetic examples: calendar, payment, full bank journey. Nothing is sent to real services. Balances and unrelated records are fictional privacy test data.
